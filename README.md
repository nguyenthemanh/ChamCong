# Chấm công (月報報告書)

Android timesheet / monthly work report app for modern phones and Galaxy Z Fold.

- Auto calendar days & weekdays by real month
- Separate UI language vs timesheet region (VI / JA / EN)
- Share PDF / JPG like the Excel sample
- Pay estimate in-app only (Excel-style formula)
- In-app update check (GitHub Releases) + author link

## Requirements

- Android 8.0+ (API 26)
- JDK 17, Android SDK 35

## Build

```bat
gradlew.bat assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
